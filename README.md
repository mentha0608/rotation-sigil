# Rotation Sigil

DQX向けのボスローテーション確認ツールです。  
ルベランギス向けのタイマー機能も統合しています。

## 主な機能
- ボスごとのローテーション表示
- HP帯ごとの切替
- マウスホイールによるHP段階移動
- 文字サイズ調整
- ルベランギスタイマー
  - サークルカラミティ / グランドカラミティ
  - 事前読み上げ
  - 次案内
  - メトロノーム
  - 音量調整
  - ±0.5秒補正
  - 停止

## 対応ボス
- ルベランギス Lv2 / Lv3
- （ほか対応ボスがあれば追記）
