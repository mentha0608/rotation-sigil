# Rotation Sigil

DQX向けのボスローテーション確認ツールです。  
現在は以下のボスデータに対応しています。

- ノクゼリア Lv1
- ノクゼリア Lv2
- 厭悪のルベランギス Lv3

## 概要

Rotation Sigil は、ボスのHP段階ごとのローテーションやモードを確認するためのツールです。

主に以下の用途を想定しています。

- 戦闘前のローテーション確認
- 戦闘中の現在モード確認
- HP段階ごとの行動候補確認
- 反撃行動やランダム行動の整理

## 主な機能

- ボス切り替え
- HP段階切り替え
- ローテーション / モード切り替え
- 一覧モード
- 選択中のみ表示モード
- ミニマル表示
- 不透明度設定
- 前回選択したボスの保存
- ウィンドウ位置・サイズの保存
- アクティブ時ショートカット操作

## 表示モード

### 一覧モード

現在選択しているHP段階のローテーションを一覧表示します。  
複数モードをまとめて確認したい場合に向いています。

### 選択中のみ表示

現在選択しているローテーションだけを表示します。  
戦闘中に表示領域を絞りたい場合に向いています。

### ミニマル表示

HP段階ボタンやローテーション切り替えボタンを隠し、ローテーション表を中心に表示します。  
設定ボタンは残るため、後から設定を戻すこともできます。

## ショートカット

ショートカットは、Rotation Sigil のウィンドウがアクティブな時のみ動作します。

| キー | 動作 |
|---|---|
| `[` | HP段階を前へ |
| `]` | HP段階を次へ |
| `,` | ローテーション / モードを前へ |
| `.` | ローテーション / モードを次へ |
| `Ctrl + ,` | 設定パネルを開閉 |
